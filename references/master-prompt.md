# 主提示词模板（Master Prompt）

本文件是摄影再设计海报的可复用提示词。先从参考照片确定下列变量，再把模板正文整体复制给参考图生图/图片编辑工具（参考图由工具参数传入，不写进文字）。

## 变量

| 变量 | 含义 | 取值 |
|---|---|---|
| `{{ANCHORS}}` | 照片中最具辨识度的视觉锚点 | 具体描述，如人物姿态、服装轮廓、花卉、建筑、运动轨迹、光影关系 |
| `{{TREATMENT}}` | 下半部分的抽象手法 | 高反差版画 / 丝网印刷 / 水墨线描 / 半透明影像拼贴，选 1–2 种 |
| `{{SYMBOL}}` | 据主题设计的专属视觉符号 | 见下方映射，按照片主题选取 |
| `{{ACCENT_COLOR}}` | 唯一强调色 | 朱砂红 / 青蓝 / 橙黄 / 深绿，四选一 |
| `{{TITLE}}` | 简短英文标题 | 1–3 个单词，拼写正确 |
| `{{SUBTITLE}}` | 辅助说明文字 | 年份/媒介/地点/作者等，可留空后删除该行 |

### 锚点 → 专属符号

- 风 → 流动线条和飘带
- 花 → 植物轮廓和花瓣扩散
- 人物 → 剪影和姿态线
- 运动 → 弧形轨迹和速度纹理
- 空间 → 几何色块和留白

## 模板正文

```text
请根据上传的真实摄影图片，制作一张现代艺术展览级摄影再设计海报。整体采用 3:4 竖版构图，上下严格 50% 分区。

【上半部分】
完整保留原始摄影照片，逐像素保持人物、动物或景物的身份、数量、动作、比例、空间关系、真实材质和原始光影。只进行轻微艺术调色，不改变主体，不增加不存在的元素。

【下半部分】
以暖象牙白艺术纸作为背景，将照片重新转译为现代主义编辑海报设计。
本照片最具辨识度的视觉锚点是：{{ANCHORS}}。
不要直接复制照片，而是进行视觉抽象：将主体处理为{{TREATMENT}}，保留主体核心轮廓，使其仍然可以识别。
根据照片主题加入专属视觉符号：{{SYMBOL}}。
加入少量现代主义几何元素：细线、圆弧、矩形色块、局部透明层。几何元素必须来源于原图，不允许随机装饰。

【色彩控制】
采用暖白、墨黑作为基础，加入 1 种主要强调色：{{ACCENT_COLOR}}。保持低饱和、高级、克制。

【文字排版】
艺术展览级文字排版：一个简短英文标题 “{{TITLE}}”；少量辅助说明文字 “{{SUBTITLE}}”。小字号、宽字距、非对称排版。文字作为视觉结构的一部分，不遮挡主体，拼写准确、无乱码。

【整体效果】
像独立艺术杂志封面、现代东方艺术展海报、实验印刷作品。高清，1536×2048 以上；纸张纤维、丝网印刷颗粒、局部缺墨、轻微套色偏移、自然手工印刷痕迹。

【禁止】
商业广告风、巨大标题、复古宣传画、随机几何拼贴、过度鲜艳颜色、人物变形、改变动作、增加人物、AI 塑料质感、3D 效果、水印、Logo、乱码文字。
```

## 填充示例（仅示意，实际以照片为准）

- `{{ANCHORS}}`：奔跑中人物的侧身姿态、被风吹起的外套下摆、斜向光影
- `{{TREATMENT}}`：高反差版画效果叠加半透明影像拼贴
- `{{SYMBOL}}`：运动的弧形轨迹与速度纹理，辅以风的流动线条
- `{{ACCENT_COLOR}}`：朱砂红
- `{{TITLE}}`：MOTION STUDY
- `{{SUBTITLE}}`：SILKSCREEN / 2026
